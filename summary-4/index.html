Datasets

This section provides documentation for all catalyst-related datasets in the Open Catalyst Project. These datasets are used to train and evaluate machine learning models for heterogeneous catalysis applications.

Tip

For most new users, we recommend starting with the UMA model, which has been trained on all of these datasets and provides state-of-the-art performance.

OC20

The foundational Open Catalyst 2020 dataset with 133M+ DFT calculations for adsorbate-surface systems.

OC20-mAds

Multi-adsorbate extension of OC20 including coverage effects on catalyst surfaces.

OC20Dense

Dense sampling of adsorbate configurations for adsorption energy calculations.

OC20NEB

NEB trajectories for transition state calculations including desorptions, dissociations, and transfers.

OC22

Open Catalyst 2022 dataset focusing on oxide electrocatalysts with total energy predictions.

OC25

Solid-liquid interface dataset with 8M DFT calculations for electrocatalysis applications.

OCx24

Experimental validation dataset bridging computational and experimental catalysis research.
